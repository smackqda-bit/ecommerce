# ВНЕ ПЛАНА — интернет-магазин мерча (портфолио)

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Motion · Lenis · Zustand.
Без оплаты и без БД: корзина, избранное, заказы и вход хранятся в localStorage, оплата и вход по коду — моки.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # проверка продакшен-сборки
```

Нужен Node.js 20.9+.

## Структура

- `data/products.ts` — все товары, цены, размеры, ракурсы фото. Страницы `/product/[slug]` генерируются отсюда.
- `lib/store.ts` — Zustand-стор (корзина, избранное, контакты, заказы, мок-пользователь).
- `components/motion.tsx` — анимационные примитивы: `Reveal`, `LineReveal`, `ImageReveal`, `RouteLine` (рисующийся пунктир), `RollingNumber`, `Stagger`.
- `components/SmoothScroll.tsx` — Lenis + `MotionConfig` (уважает «уменьшить движение» в системе).
- `app/globals.css` — дизайн-токены (`@theme`), утилиты `wrap`, `eyebrow`, `link-line`.
- `public/images/products/<товар>/<цвет>-<ракурс>.jpg`, `public/images/lifestyle/`.

## Страницы

Главная, Каталог (фильтры в URL), Товар, Корзина, Оформление (3 шага), Спасибо / статус оплаты,
О бренде, Помощь, Контакты, Поиск, Избранное, Вход по коду, Личный кабинет, Политика данных, Условия продажи, 404.

## Демо-сценарии

- Оформление → шаг 3 → «Демо · ответ банка»: оплачено / ожидание (через 6 с станет «оплачено») / ошибка.
- Вход: подходит любой 6-значный код.
- Корзина с плашкой «изменилась цена»: `/cart?state=price-changed`.
- В кабинете у заказа можно переключать статус оплаты.

## Что заменить перед показом

Цены, состав, рост модели, реквизиты ИП, контакты — примерные значения (в `data/products.ts`, `components/Footer.tsx`, `app/contacts/page.tsx`, правовые страницы).
